# `logit`

Fit a binary-response logit model.

!!! question "When to use"
    How do I model a 0/1 outcome as a function of predictors?

## Syntax

```text
logit y x1 x2 [, robust cluster(var) noconstant]
```

## Examples

```text
logit insured age bmi
```
