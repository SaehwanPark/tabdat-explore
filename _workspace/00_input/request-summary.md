# Request Summary: Silent Plot Drawing & Clickable File Links

## Goal
1. Make plot-drawing silent by default:
   - Plots generated by commands (`histogram`, `scatter`, `bar`, `bayesplot`, `estat report`) are saved to files silently without automatically popping open external applications or browsers by default.
   - `graph_open` defaults to `False` (`off`).
2. Provide clickable `file://<path>` URI links in the output when plots are generated (e.g., `Saved plot: file:///path/to/plot.svg`).
3. Update tests and test harness to ensure test suites never open a browser or external viewer window under any circumstances.

## Phase Fit
Cross-phase UX & Tooling Stabilization.

## Touched Surfaces
- `src/tabdat/config.py`: Default `graph_open = False`.
- `src/tabdat/formatter.py`: Format `PlotResult` with `file://` URI link (`Path(path).resolve().as_uri()`).
- `tests/conftest.py`: Autouse fixture guaranteeing no external browser/application opener process is spawned during tests.
- `tests/test_cli.py`: Update plot assertions and default config header assertions to expect `file://` URIs and `graph_open=off`.
- `tests/test_config.py`: Add assertion for default `graph_open == False`.
- `integrated_testing/run_e2e.py`: Update scenario expectations for plot URI output.
- Documentation: `docs/user-guide.md`, `ARCHITECTURE.md`, `SPEC.md`.

## Assumptions
- `PlotResult` terminal formatting uses RFC 8089 file URI via `Path(path).resolve().as_uri()` for terminal clickable links.
- `set graph_open on|off` and `.tabdat.toml` configuration remain functional for users who explicitly wish to enable auto-opening.
- Test suites must have an invariant that external opener processes are never invoked.

## Non-Goals
- Altering the underlying chart generation engines (Altair/Matplotlib).
- Changing plot naming conventions or directory collision resolution.
